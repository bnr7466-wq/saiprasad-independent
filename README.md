# Campaign Photo Frame Generator (GitHub Pages)

A mobile-first campaign photo frame generator web app built with HTML, CSS, and HTML5 Canvas.

## Files Included
- `index.html` - Main page structure and 6-step campaign frame builder UI
- `style.css` - Responsive mobile layout, color themes, and card styling
- `app.js` - HTML5 Canvas rendering, drag-to-pan/zoom photo controls, Telugu/English language switching, and WhatsApp share/download logic

## Setup & Deployment
1. Create a public GitHub repository (for example, `yourusername.github.io`).
2. Upload `index.html`, `style.css`, and `app.js` to the root directory.
3. Optional: Create an `assets/` folder with `candidate.png` and `leader.png` (transparent PNGs) and update `CANDIDATE_IMG_URL` and `LEADER_IMG_URL` at the top of `app.js`.
4. Enable **GitHub Pages** under **Settings > Pages > Source: Deploy from a branch (`main`)**.
